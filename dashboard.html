Terms of Service & Privacy Policy

1. Credential Security: AWS access keys are held transiently in memory for up to 60 minutes solely to perform resource audits and execute requested actions. Credentials are never written to disk or logged.

2. Recommended IAM Permissions: We strongly advise creating dedicated IAM users with standard ReadOnlyAccess policies unless initiating automation actions.

3. Waste Calculation Estimates: Financial metrics are calculated using published regional baseline pricing. Users should review infrastructure before performing sleep or stop actions.

4. Privacy Guarantee: Infrastructure data is not tracked or sold to third parties.
